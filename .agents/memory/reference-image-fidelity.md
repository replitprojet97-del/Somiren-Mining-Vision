---
name: Reference image fidelity
description: Why the screenshot's actual photographs were retained instead of using other imported brand photos.
---

For the collaborator design reference, preserve the reference photograph compositions rather than substituting visually similar stock or imported brand assets. Improve resolution only with verified matching originals.

**Why:** The requested match explicitly includes the images. Available imported portrait and mining photographs were not identical to the supplied JPEG, so cropped reference photographs were chosen for fidelity despite their limited resolution. Names and roles are not unique account identifiers; treating a failed photo response as permission to show the reference portrait could undo someone's explicit removal.

**How to apply:** Keep the distinction between design fixtures and production information: screenshot example names, counts, dates and statuses are not instructions to overwrite live account data. A reference portrait must not become every user's identity image. Grant the legacy portrait only through server-confirmed account eligibility, never through a name/role match alone, and never restore it after a user removes it or when photo status cannot be loaded.
